{{- /* aeo-allowed.html — the pages an AEO file is allowed to name. Context: a dict of `pages` and `disallow` (aeo-gate.html's), and an optional `root`. Returns the pages whose RelPermalink does not sit under one of the excluded prefixes. Prefix rather than exact match, because that is what a robots.txt `Disallow:` means and the two have to agree: `Disallow: /drafts/` covers every page under it, and a llms.txt that listed the children while robots.txt excluded the parent would be the disagreement this exists to prevent. The comparison is against the path as robots.txt spells it, which is the path from the site root and not from the host. RelPermalink carries the baseURL's sub-path — "/site/posts/hidden/" where the config says "/posts/hidden/" — so matching on it directly excludes nothing at all on exactly the deploy shape a GitHub Pages project site has. `root` overrides the site root to strip, and exists for the one caller that is not rendering a single language: sitemap.xml is built once from every site at once, where the `site` global is whichever language came first and matching a Portuguese page against the English root excludes nothing. Every other caller omits it. Nothing here may print: this partial returns a value, so every action is whitespace-trimmed. */ -}} {{- $disallow := .disallow -}} {{- $root := or .root site.Home.RelPermalink -}} {{- $keep := slice -}} {{- range .pages -}} {{- $page := . -}} {{- $path := printf "/%s" (strings.TrimPrefix $root $page.RelPermalink) -}} {{- $blocked := false -}} {{- range $disallow -}} {{- if and . (hasPrefix $path .) -}}{{- $blocked = true -}}{{- end -}} {{- end -}} {{- if not $blocked -}}{{- $keep = $keep | append $page -}}{{- end -}} {{- end -}} {{- return $keep -}}
