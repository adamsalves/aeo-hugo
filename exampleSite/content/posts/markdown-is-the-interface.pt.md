## A fonte é a carga útil

O Hugo já transforma markdown em HTML. Publicar o próprio markdown custa um
formato de saída e dá a todo leitor de IA a estrutura, em vez de uma página que
ele precisa descascar. O formato `MARKDOWN` no `hugo.toml` é o truque inteiro.
